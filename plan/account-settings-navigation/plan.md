# Accounts and Settings navigation

- Merge Provider and Accounts into Platform with collapsible provider groups, icons, explicit Log in / Log out controls, and Codeforces handle.
- Prefer a human name or email and suppress saved internal IDs and protocol status suffixes.
- Navigate Settings tabs with Tab / Shift+Tab and arrows, protecting empty sections and text inputs.
- Keep global commands independent of panel contexts and restore focus to Debug when returning from full-window views.
- Run regression checks, commit the scoped changes, and deploy locally. The user will verify native UI interaction.
